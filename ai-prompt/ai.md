# 项目背景

项目名称：

高校实验资源协同管理平台

项目定位：

这是一个已经完成基础功能的项目。

本次开发是在已有项目基础上升级和完善功能。

禁止重写已有模块。

禁止创建重复功能。

优先复用已有代码。

修改前先分析当前项目结构和数据库结构。

如果已有代码能够满足需求，则直接复用。

# TypeScript强制规范

项目必须全面使用TypeScript。

禁止生成：

.js
.jsx

必须使用：

.ts
.tsx

------------------------------------

前端：

.tsx

用于：

页面组件
业务组件

.ts

用于：

hooks
utils
api
types
constants

------------------------------------

后端：

.ts

用于：

Controller
Service
Model
Middleware
DTO
Enum

------------------------------------

所有接口必须定义类型：

禁止：

const user:any

必须：

interface User {

 id:number

 username:string

 role:'admin'|'student'

}

------------------------------------

API统一返回：

interface ApiResponse<T>{

 code:number

 message:string

 data:T

}

禁止：

any

------------------------------------

所有Props必须定义interface：

例如：

interface DeviceCardProps{

 id:number

 name:string

 status:DeviceStatus

}

禁止：

props:any

------------------------------------

React必须使用函数组件：

允许：

const UserPage:React.FC=()=>{}

禁止：

class UserPage extends React.Component

------------------------------------

Form必须使用泛型：

允许：

const [form]=Form.useForm<UserForm>()

禁止：

Form.useForm()

------------------------------------

修改已有jsx项目：

优先：

jsx -> tsx

js -> ts

保留原目录结构。

禁止：

重建项目

禁止：

创建第二套页面

禁止：

UserNew.tsx

User2.tsx

NewUserService.ts

LabControllerNew.ts

等重复文件。

# 项目架构规范

Controller：

只负责：

参数校验

调用Service

返回结果

禁止：

写业务逻辑

调用其他Controller

------------------------------------

Service：

负责：

业务逻辑

权限判断

事务管理

禁止：

Service循环依赖

------------------------------------

Model：

只负责：

数据库映射

禁止：

写业务逻辑

------------------------------------

所有权限：

统一通过：

JWT中间件

------------------------------------

所有状态：

必须使用枚举。

禁止：

'正常'

'故障'

'待审核'

等魔法字符串。

------------------------------------

新增核心功能：

预约时间冲突检测

规则：

同一个实验室

同一天

如果时间段存在交集

则禁止预约。

------------------------------------

例如：

已有：

14:00~16:00

禁止：

13:00~15:00

14:30~15:30

15:00~17:00

允许：

10:00~12:00

16:00~18:00

------------------------------------

返回：

当前时间段已被预约，请选择其他时间。

------------------------------------

管理员审批预约时：

必须再次检查时间冲突。

防止：

两个待审核预约

同时审批通过。
