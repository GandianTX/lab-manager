## 缺失功能分析及完成计划

根据 `最终版功能.md` 对比现有代码，问题主要集中在前端页面功能缺失，后端 API 基本完整。

### 问题根因分析

路由配置和页面组件都存在，但用户反馈"看不到导航栏和管理功能"，核心原因是：

1. **登录后初始状态恢复有问题** — `app.tsx` 中 `getInitialState` 仅从 `localStorage` 读取用户信息，没有通过 API 验证 token 有效性，导致刷新页面后 `currentUser` 可能为空，菜单不显示
2. **菜单名称不够明确** — 管理员看到的"预约"和"报修"应改为"预约审核"和"报修审核"，实验室/设备应改为"实验室管理"/"设备管理"
3. **部分页面功能不完整** — 学生端缺少实验室详情查看、设备详情查看、实验室状态提示等
